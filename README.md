## Файлы

| Путь | Назначение |
| --- | --- |
| index.html | Исходный интерфейс и исторические встроенные JS-обновления |
| cloud/worker.mjs | Вход, права, API общей базы |
| cloud/auth.mjs | Проверка хешей паролей |
| cloud/client.mjs, shared.mjs | Синхронизация и объединение изменений |
| cloud/users.mjs | Статус паролей и управление ими администратором |
| cloud/migrations/ | Схема D1 |
| scripts/ | Сборка, экспорт, подготовка конфигов, восстановление |
| tests/ | Синхронизация, вход, права, смена паролей |
| wrangler.jsonc | Действующая публикация в исходном аккаунте |
| wrangler.account.json | Генерируемый конфиг нового аккаунта; не в Git |
| wrangler.migration.json | Генерируемый конфиг нового Worker/D1; не в Git |
| .private/ | Закрытые снимки и временные файлы; не в Git |

## Проверки

Нужен Node.js 22+. Из корня проекта:

```text
npm ci
npm test
npm run build
```

При миграции не запускать npm run deploy: он использует текущий аккаунт.
Команды с явным конфигом нового аккаунта есть в инструкции переноса.

## Полный пакет

В закрытом [репозитории резервных копий](https://github.com/vlad-ultra/Glasfaser-WebApp-Backups/releases/tag/migration-2026-10-28):
`Glasfaser-Migration-Windows-2026-10-28.zip` — исходники, полный прикладной
снимок D1 `.gfb`, манифест SHA-256, инструкции. Снимок включает хеши паролей,
но не активные сеансы и не OAuth-токены Cloudflare. Пользователи входят заново
с прежними заданными паролями.

Этот репозиторий содержит только исходный код и открыт временно для переноса.
Рабочие данные вынесены в отдельный закрытый репозиторий Glasfaser-WebApp-Backups.
Для другого участника передать ZIP напрямую или предоставить ему доступ к резервным копиям.

Снимок отражает состояние на момент экспорта 28.10.2026. Если после этого
продолжается работа, перед переключением нужен новый экспорт.
